# IBM Bob Technology Usage in WasteWise

## Overview

WasteWise is a digital platform designed to encourage responsible waste management by making waste identification, disposal guidance, sustainability tracking, and rewards more accessible and engaging.

IBM Bob was used as an AI-assisted development tool during the development of WasteWise. It supported the development workflow by helping the team work more efficiently with code, understand the project structure, improve implementation ideas, and troubleshoot technical challenges.

## How IBM Bob Was Used

### Code Development and Assistance

IBM Bob was used to assist with development tasks by providing guidance while working on different parts of the application. It helped the team understand code structure, explore implementation approaches, and improve the development workflow.

### Debugging and Problem Solving

During development, IBM Bob supported troubleshooting by helping identify possible causes of errors and suggesting approaches to resolve coding and integration issues. This made it easier to understand technical problems and iterate on solutions.

### Code Understanding and Improvement

IBM Bob was also used to understand existing code and project components, particularly when working with different parts of the application. Its assistance helped developers review logic, understand workflows, and make improvements while maintaining consistency within the project.

## Development Workflow

The development process involved using IBM Bob as an AI-assisted companion alongside the team's regular development tools and workflows. Developers used its assistance to:

* Understand and navigate the project codebase.
* Get guidance on implementing and improving application features.
* Troubleshoot coding and integration issues.
* Explore solutions and refine implementation approaches.
* Improve development productivity and reduce time spent resolving common technical challenges.

The team reviewed and integrated suggestions based on the requirements and architecture of WasteWise rather than relying on automated output without validation.

## Impact on the Project

Using IBM Bob helped support a more efficient development process by providing assistance during coding, debugging, and code understanding. It enabled the team to focus more on building the core WasteWise experience while improving collaboration and problem-solving throughout development.

IBM Bob was used as a development support technology and did not replace the team's decision-making or ownership of the project. The final implementation and integration of features were reviewed and adapted according to the project's requirements.

## Conclusion

IBM Bob contributed to the development of WasteWise by supporting coding, debugging, code understanding, and problem-solving activities. Its use as an AI-assisted development tool helped streamline parts of the development workflow and supported the team in building a more structured and user-focused waste management platform.
